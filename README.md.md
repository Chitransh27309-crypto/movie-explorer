# Movie Explorer

A responsive movie discovery web app built with React, Tailwind CSS, and the TMDB API.

## Features

- Browse popular movies
- Movie ratings and release years
- Search movies
- Dark and light mode
- Bookmark movies
- Persistent bookmarks using localStorage
- Responsive design

## Tech Stack

- React
- Vite
- Tailwind CSS
- TMDB API
- React Router

## Getting Started

```bash
npm install
npm run dev
